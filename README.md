# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 功能开关、发布计划、审计记录三类业务对象。
- 规则组合、模拟用户命中、定时生效。
- 产品/研发双审批、开始灰度、紧急停止、回滚和恢复草稿。
- 离线提示、VeeValidate + Zod 精确校验和 localStorage 持久化。

## 分档灰度（核心）
放量不再是一推到底的滑块，而是发布计划里的多个档位，每档固定**比例 + 观察时长**
（默认 5%/30min → 20%/60min → 50%/120min → 100%/240min，可在开始前增删改）。

- **门禁自动判定**：观察时长走满后，最新错误率必须**低于入档基线**才算“降下去”，
  门禁通过后值班员才能推进下一档；否则自动**退回上一档并冻结**，按失败档命中范围
  （灰度桶，每 10 桶一个范围片）发起**快照收回**。第 1 档失败则归零全量关闭。
- **收回断点续传**：某个范围片收回失败即停，该片成为断点、其余片记为待收项；
  点击“从断点重试收回”只重试断点片并继续推进，已收回快照保持终态。
  控制台可“注入下一片收回失败”演示该过程。
- **档位变化快照重算**：未收完的快照在档位回退后按新命中范围整体重算——
  仍在范围内的刷新 revision 续收，超出范围的作废；连续回退不丢弃进行中的收回任务。
- **并发值班**：推进/停止携带决策序号 `revision` 做 CAS。两名值班员基于同一版本同时提交时，
  先处理的操作落地并推进 revision，后到者按新档位重新判断（`rejudge`）：
  动作仍合法则落地（并标注“后到操作”），不适用则拒绝。
- **审计去重**：一次回退无论伴随多少次收回重试或快照重算，审计时间线只出现一条
  （按 `dedupKey` 去重）。
- 控制台提供虚拟时钟“快进 30 分钟/1 小时/4 小时”，无需真实等待即可走完观察期。

